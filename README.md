# Feldman Flashlight

A touch-first Android flashlight with flash, screen-light, safety-signal, Quick Settings tile, personalization, and landscape controls.

## Build

Open the project in Android Studio or run:

```shell
./gradlew assembleDebug
```

Debug builds use Android's default debug key. To use a local signing key for debug and release builds, copy `keystore.properties.example` to `keystore.properties` and fill in your local values. The resulting file is ignored by Git.

## Privacy

Feldman Flashlight does not collect or transmit personal data. See the [privacy policy](privacy-policy.html) for the full disclosure.
